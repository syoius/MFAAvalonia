## 四、本轮交付范围

### 1. 桌面 Copilot 导航与独立状态

恢复并接入桌面 Copilot 功能，沿用上游 UI 和执行架构，保留既有 fork 的必要行为。建立“资源定义 → 实例 Copilot 保存状态 → 本次执行快照”的数据链路：

- 按当前资源定义及旧名称兼容规则找到 Copilot 入口，恢复实例自己的选项、重复次数、输入、多选和嵌套状态。
- 保存对象与运行对象深拷贝，避免通过主页任务对象、同名匹配或 Clone 副作用改变主页勾选和选项。
- 复用统一 `TaskOptionGenerator` 和保存回调，不维护另一套容易漂移的选项控件生成逻辑。
- 主页无同名任务、未勾选或选项不同，都不影响 Copilot 的独立数据来源。默认入口缺失时清楚提示并保留原状态，不自动创建主页任务。
- 页面、异步回调、实例和资源/配置代际明确对应；切换标签、重载、导入后，旧回调不能写入新对象或其他实例。

### 2. 实际执行集合、启动接受与停止完成

结合当前生产代码落实实施方案第 5.2 节，不只适配方法签名：

- 复用能接受“目标实例 + 实际任务集合”的资源、设备和 input 校验，并合并该实例有效的 global/controller/resource options。
- 本次 runId 的状态、耗时、失败、取消和收尾围绕本次实际执行集合，不能再默认遍历主页持久化列表。
- 提供明确的启动接受/拒绝结果，不把调用返回或启动前观察到 Idle 当成启动成功。
- 实例、来源和 runId 贯穿回调；同名任务、旧运行的延迟通知不能误更新主页或结束新运行。
- 停止后的占用释放以后台运行和清理真正完成为准，不能只依赖 UI IsRunning=false。
- 接入既有 `CompatibilityTimerRuntime` 的预约/占用及规则时效边界，保留 P0～P3 的定时、导入、迁移及失败冻结保护；不重写上游执行引擎或绕过其队列/Tasker 状态机。

### 3. 共享资源写入、回滚与重载

首轮保留“共享活动作业”语义，不扩展为每实例独立作业覆盖层：

- 按实际资源路径集合处理互斥，覆盖同路径不同资源名、重叠目录、平台大小写和链接别名。
- 在统一运行接入处登记占用，覆盖主页、Copilot、定时、CLI、总控台等现有启动来源；写入前重新检查正在启动、运行、停止等状态。
- 解析/下载可提前完成；激活前取得排他写入资格，在暂存区验证，只替换受管理的 Copilot 活动文件，保留 `copilot_config.json` 及其他用户文件。
- 安全释放需要重建的资源对象；替换或重载失败时回滚，并保持页面状态、实例可运行状态和磁盘一致。
- 资源代际变化通知所有使用同路径的实例，空闲实例下次运行前也必须重载。
- 避免持同步锁跨越长时间网络/控制器操作；取消和异常必须释放占用。
- 为 P5 录制接入保留统一占用接口并用可观察替身验证边界，本轮不实施完整录制功能，也不能把接口存在当作录制验收通过。

测试用于证明行为和回归风险，不追求数量。必须调用相关生产数据、模型、运行协调或文件替换路径；设备/网络副作用可替换，但不能只测试一份独立复制的实现。

至少覆盖：

- 主页没有/未勾选同名任务，Copilot 仍独立运行；编辑、保存、重复次数和选项不会污染主页或其他实例。
- A/B 实例、切换页面及资源重载后，旧保存回调/旧运行回调不能串实例、串代际或结束新运行。
- Copilot 非法输入/资源缺失校验、启动拒绝、忙碌竞争、延迟停止、取消及异常收尾；实际集合的耗时和状态正确。
- 同路径不同资源名、重叠资源、定时或其他入口在写入前后竞争；取得资格后仍重新验证，不与运行/停止/模拟录制占用并发修改文件。
- 替换失败、重载失败、取消后的回滚与锁释放；共享路径其他实例的重载；已有用户文件不被误清理。
- 本地文件、代码、作业集、非法响应、主站失败回退及取消等协议边界。
- 现有 60 组回归继续通过；P4 必须调整公共契约时更新真实期望与迁移兼容说明，不能放宽断言掩盖 R1～R6 回归。

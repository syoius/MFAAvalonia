## 3. P7：总控台、进度与实例可编辑性

### 3.1 组合上游与 fork 的桌面总控台

以当前上游式 MonitorView / MonitorViewModel / MonitorItemViewModel 及共享 LiveView 为基础，补回旧 fork 的内嵌启停、当前任务名、主任务进度、竖屏默认布局和圆角显示。

- 保留现有卡片排序、缩放、右键菜单、单击跳转、全屏及多实例能力，不用旧总控台整体替换新版。
- 内嵌按钮始终操作卡片所属实例；阻止按钮点击冒泡造成意外跳转。启停调用已有生产入口并尊重准入拒绝、停止清理和录制约束，不能直接切换布尔值冒充成功。
- 进度来自 P4 已接入的实际运行集合及运行身份，包含独立 Copilot；不能按主页勾选集合或剩余队列长度推算全部业务状态。
- 主任务总数不包含连接、预处理等辅助步骤；重复次数与主页口径一致，失败、跳过、取消与成功有区分。队列已空但原生清理未完时，不显示为已经释放、可重新启动。
- A/B 实例交替运行、切页、重启同一实例、旧回调迟到时，名称、进度、按钮状态不能串到另一个实例或新运行。

竖屏默认值仅用于没有有效用户布局的情况；已有用户布局、排序和缩放优先保留。复用已有桌面导航与 RootViewContent，不设计一套新 UI。

### 3.2 两项已确认的界面同步任务

这两项来自 P6 最新审查，属于本轮必做内容，不需要重新证明是否应保留。

**全局运行状态收尾。** `RootViewModel.IsRunning` 当前由队列变化刷新，可能在真实清理完成后仍为 true。核对全局状态与实例状态的实际消费者，在启动、正常完成、异常、手动停止及最后占用释放时正确更新相关显示和命令可用性。区分全局运行、当前实例忙碌和录制占用，不用一个全局布尔值锁住所有实例，也不提前释放执行资格来让界面看似空闲。

**AfterTask 回滚后的显示。** A → B → A 刷新可能把当前控件显示为准备值 None；命令拒绝后，实际配置已恢复 ShutDownOnce，但控件没有重读。本轮应使可见选择与实际有效配置一致：

- 处理成功恢复、恢复失败或保留用户新值后的正确显示，不能显示恢复成功而实际未成功。
- 更新前确认显示的实例及命名配置仍与目标匹配；后台实例或非活动来源快照不能覆盖当前页面。
- 使用 P6-R2 的不写回刷新方式，避免显示同步推进 AfterTask 写入版本。保持真实用户修改 None、其他动作以及来源配置切换的 R1/R2 保护。
- 回归断言应同时检查控件属性/通知、内存和磁盘有效值；覆盖 A → B → A、拒绝/异常，以及等待期间真实编辑。不能仅看磁盘正确就宣布显示验收完成。

相关入口包括 `MaaProcessor`、`RootViewModel`、`AutomaticAfterTaskCoordinator`、`InstanceConfiguration.TryChangeAfterTask`、`StartSettingsUserControlModel.RefreshAfterTaskFromConfiguration`。具体实现由你判断，不重写已通过的全局结束策略。

已排除的猜测保持关闭：当前 Avalonia 的程序性 `Shutdown()` 不会因 Closing 的 Cancel 而被拦住。不要因此改写手动退出或 CLI 的公共契约；本轮测试仍不得真正关闭用户程序或执行系统关机/重启。

### 3.3 当前实例设置、布局与延迟回调

空闲 B 的实例任务与控制器设置应能在 A 运行时编辑；A 自己仍忙碌时相关配置继续受保护。共享资源修改、全局设置和录制目标按实际作用域约束，不能把全局禁用一律去掉。

布局读写捕获所属实例/配置身份。按需将旧 fork 的 GridLengthStorage 行为适配到当前架构，避免拖动或异步切换后把列宽写给新 ActiveTab。保留已有 Dashboard layout 的键、hash/后缀值；无法识别的布局只回退布局，不能重置任务、选项或其他配置。不要为此新增布局校验哈希。

检查桌面页面、服务注册、语言键与资源字典的连接。保留中文文案和上游其他语言支持，缺翻译使用项目既有回退。

### 3.4 图片、订阅和页面生命周期

`MonitorItemViewModel.Image` 引用任务页面拥有的 LiveViewImage，监控页不是其独占所有者。不要复制旧 fork 的 `Image.Dispose()`；由实际图像所有者负责释放，消费者在离开/隐藏/关闭时解除自己的引用和订阅。

覆盖总控台反复进入退出、隐藏/恢复、关闭卡片或实例，以及任务页与总控台同时消费画面。离开一个消费者不能破坏另一个消费者，关闭实例后也不能留存旧回调更新新页面。仅调整本轮涉及的图像/订阅路径，不另建截图引擎或通用泄漏检测框架。
